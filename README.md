# Portal MFE updater (public)

Public channel for **Portal MFE** Windows desktop updates. No application source lives here.

| File / asset | URL |
|--------------|-----|
| Manifest | https://raw.githubusercontent.com/MFE-Usine/mfe-portal-updater/main/latest-web.json |
| Installers | GitHub Releases on this repo (`Portal-MFE_*_x64-setup.exe`) |

CI on private `MFE-Usine/mfe_new_platform` publishes releases and updates `latest-web.json`.
